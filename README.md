# Petrol Pump Counter

A React app that recreates the look of an old mechanical petrol pump litre
counter: rolling digit wheels, a "LITRES" plate, and Start/Stop and Reset
buttons.

## Running it

```
npm install
npm run dev
```

Then open the local URL Vite prints (usually http://localhost:5173).

## Building for production

```
npm run build
```

The output is written to `dist/`.
